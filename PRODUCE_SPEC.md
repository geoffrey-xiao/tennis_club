# Product Specification: Tennis Club Website

## Product Vision

Build a daily tennis hub for tennis fans.

The product helps users quickly answer:

1. What happened in tennis today?
2. Which matches are worth watching?
3. What happened to my favorite players?
4. How can I understand tennis better as a beginner?
5. Where can I find local tennis courts and partners in the future?

## Target Users

### Primary Users

- Tennis fans who follow ATP/WTA matches
- Beginner tennis players
- People who want quick daily tennis updates
- Users who want to follow specific players

### Future Users

- Local tennis players looking for partners
- Tennis coaches
- Tennis clubs
- Tennis equipment buyers

## MVP Scope

### Pages

1. Home page
2. Daily Briefing page
3. News listing page
4. Article detail page
5. Player listing page
6. Player profile page
7. Learn page
8. Glossary page
9. Newsletter subscription page
10. About page

## Core Features

### 1. Home Page

The home page should include:

- Hero section
- Today’s Tennis Briefing card
- Today’s recommended matches
- Latest articles
- Featured players
- Beginner guide links
- Newsletter CTA

### 2. Daily Tennis Briefing

Each briefing should follow this format:

- Headline
- Top story
- Key results
- Matches to watch
- Player updates
- One-sentence opinion
- Source links

Important: The briefing must be written in original language. Do not copy full news articles.

### 3. News Categories

Initial categories:

- ATP
- WTA
- Grand Slam
- Match Preview
- Match Review
- Gear
- Beginner

### 4. Player Profiles

Each player page should include:

- Name
- Country
- Age
- Playing style
- Strengths
- Weaknesses
- Recent news
- Recent results
- Related articles

Initial players:

- Carlos Alcaraz
- Jannik Sinner
- Novak Djokovic
- Iga Świątek
- Aryna Sabalenka
- Coco Gauff
- Naomi Osaka
- Daniil Medvedev

### 5. Learn Section

Beginner content should include:

- Tennis rules
- Tennis scoring system
- What is break point?
- What is tiebreak?
- How to choose a tennis racket
- Basic forehand guide
- Basic backhand guide
- Basic serve guide

### 6. Glossary

Glossary terms:

- Ace
- Double Fault
- Break Point
- Deuce
- Advantage
- Tiebreak
- Baseline
- Serve and Volley
- Unforced Error
- Winner

### 7. Newsletter

Newsletter form fields:

- Email
- Optional favorite player
- Consent checkbox

MVP behavior:

- Store subscription locally or mock the API first.
- Later integrate with Resend, Mailchimp, Buttondown, or Supabase.

## Design Direction

The design should feel:

- Clean
- Sporty
- Mobile-first
- Fast
- Editorial but friendly
- Beginner-friendly

Avoid making it look like a heavy sports betting or gambling site.

## SEO Requirements

Each article, player page, glossary page, and guide should have:

- Unique title
- Meta description
- Open Graph image placeholder
- Canonical URL
- Structured headings
- Internal links

## Content Safety and Copyright Rules

- Do not copy full articles.
- Do not scrape copyrighted images.
- Do not rehost videos.
- Use original summaries.
- Include source links.
- Use royalty-free images or generated placeholder graphics.
- Embed official videos only when allowed.
